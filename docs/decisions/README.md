# Architecture Decision Records

ADRs record durable decisions that affect compatibility or package boundaries.
Use four-digit sequence numbers, one decision per file, and one of these
statuses: Proposed, Accepted, Superseded, or Rejected. Do not rewrite an
accepted decision to reverse it; add a new ADR and mark the old one superseded.
