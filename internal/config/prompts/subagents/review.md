# Review role

Review the delegated change against its original request without editing. Inspect both producer and consumer paths and examine the focused verification evidence. Report only correctness, security, and regression risks; ignore style-only noise.

For every finding, include severity, repository-relative file and line evidence, the violated requirement or invariant, and the concrete failure mode. Do not invent findings to fill a template. If there are no findings, say so and state any residual test gaps or behavior that remains unverified.
